# Copycat Crowd - Official Marketing Website

> Official responsive marketing website and promotional portal for **Copycat Crowd: Memory Party Battle** on Google Play.

Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Canvas Confetti**.

---

## Highlights & Features

- **Signature Cartoon Game Theme**: Sunny sky gradients, drifting clouds, cartoon sun, rolling hills, and tactile press-down buttons with ink borders.
- **Hero & Live Previews**: Center stage arena view, authentic 3D aura showroom, and 1st place podium victory celebration.
- **Reflex Challenge Mini-Game**: Interactive memory challenge simulating in-game move sequences (Jump, Spin, Crouch, Wave, Punch, Kick) with combo streaks and victory confetti.
- **Moves & Packs**: Interactive showcase for Classic, Martial Arts, and Rock-Paper-Scissors custom move packs.
- **Community Market Showcase**: Categorized cosmetic showroom for rare toppers, particle auras, charms, and titles.
- **Authentic Gameplay Screenshots**: High-resolution in-game screenshots with full-screen lightbox zoom modal and keyboard navigation.
- **Mobile Responsive**: Fully responsive layout tested across viewports down to narrow mobile screens.
- **Player Support & Legal Compliance**: Direct access to Privacy Policy (`/privacy`) and Terms of Service (`/terms`) with developer support at `techsparks.co@gmail.com`.

---

## Tech Stack

- **Framework**: Next.js 15 (App Router, Static Generation)
- **Styling**: Tailwind CSS v4 + `@fontsource/fredoka`
- **Icons**: Lucide React SVG vector icons (Zero Unicode emojis)
- **Effects**: `canvas-confetti`
- **Type Safety**: TypeScript 5

---

## Local Development

```bash
# Install dependencies
npm install

# Run development server (http://localhost:3000)
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```
